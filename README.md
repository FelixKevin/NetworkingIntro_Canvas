# Back-end web ✨
The Canvas syllabus for back-end web in TI, includes both content and design.
A clickable tab system is included to link specific chapters.
Direct questions to Kevin Felix or Bert Heyman.

## Up & running 🏃‍➡️
- `npm install`

## Usage 🛠️
- *Always* do updates here, never directly on Canvas
- Run `node compile.js`
- Use the result to overwrite Canvas pages
