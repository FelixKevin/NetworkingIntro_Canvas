1.1 Variabelen & Datatypes Terug naar boven

PHP lijkt qua syntax heel erg op JavaScript, maar er zijn toch enkele belangrijke verschillen. In deze module zullen we de basis van PHP leren, zodat we later kunnen beginnen met het bouwen van een backend voor onze website.

Om variabelen te gebruiken in PHP volgen we dezelfde syntax als in JavaScript. We gebruiken het $-teken om een variabele te declareren en we kunnen deze variabele dan gebruiken in onze code:

$naam = 'Kevin';

Net zoals in Java kunnen we variabelen van verschillende datatypes gebruiken. PHP is net zoals JavaScript een dynamisch getypeerde taal, wat betekent dat we geen datatype moeten opgeven wanneer we een variabele declareren. PHP zal zelf proberen te raden welk datatype we bedoelen. Dit kan soms handig zijn, maar kan ook voor problemen zorgen wanneer we niet goed opletten.

Er zijn verschillende datatypes in PHP, hieronder een overzicht van de meest gebruikte:

  • int: een geheel getal.
  • float: een kommagetal.
  • string: een tekst.
  • bool: een boolean, kan enkel true of false zijn.
  • array: een lijst van waarden.
  • object: een object.
  • null: een variabele zonder waarde.

We volgen de volgende richtlijnen voor naamgeving van variabelen:

  • De naam van een variabele moet beginnen met een letter of een underscore.
  • De naam van een variabele mag enkel letters, cijfers en underscores bevatten.
  • De naam van een variabele is case-sensitive.

Hou rekening met de richtlijnen over goede naamgeving van variabelen. Dit maakt je code leesbaarder en zorgt ervoor dat je minder snel fouten maakt. Werk bij voorkeur met Engelse variabelenamen en gebruik waar mogelijk camelCase.

Let op met het feit dat PHP een dynamisch getypeerde taal is. Dit betekent dat PHP zelf zal proberen te raden welk datatype je bedoelt. Dit kan soms handig zijn, maar kan ook voor problemen zorgen wanneer je niet goed oplet. Probeer daarom altijd zo specifiek mogelijk te zijn wanneer je een variabele declareert.

$text1 = '12 uur';
$text2 = 'uur 12';

$number1 = 5;

$sum1 = $text1 + $number1; // 17
$sum2 = $text2 + $number1; // 5

Deze code zal géén foutmelding geven wanneer je deze probeert uit te voeren, hoewel deze wel een zeer onverwacht resultaat zal geven. Dit komt omdat PHP probeert om de tekst in de variabele $text1 om te zetten naar een getal, dit zal gebeuren van links naar rechts en omdat zowel 1 als 2 numerieke karakters zijn zal PHP hier de waarde van $text1 aanzien als 12 voor een berekening. Omdat $text2 met een letter begint zal PHP de tekst omzetten naar 0. Dit kan voor onverwachte resultaten zorgen.

Naast normale variabelen hebben we ook in PHP constanten. Een constante is een variabele die een vaste waarde heeft en die we niet kunnen aanpassen. We kunnen een constante declareren met de define-functie:

define('APIHOST', 'https://website.com/api');

De naam van een constante moet in hoofdletters geschreven worden en we kunnen geen $-teken gebruiken. We kunnen een constante gebruiken in onze code door de naam van de constante te gebruiken:

echo APIHOST; // https://website.com/api

1.2 Controlestructuren & Loops Terug naar boven

Net zoals in JavaScript kunnen we in PHP gebruik maken van controlestructuren en loops. Hieronder een overzicht van de meest gebruikte:

Dezelfde controlestructuren zijn beschikbaar:

  • if: controleert of een bepaalde voorwaarde waar is.
  • else: wordt uitgevoerd wanneer de voorwaarde van de if niet waar is.
  • elseif: wordt uitgevoerd wanneer de voorwaarde van de if niet waar is en een andere voorwaarde waar is.
  • switch: controleert een variabele op verschillende waarden.

Enkele voorbeelden:

$a = 5;
$b = 10;

if ($a > $b) {
    echo 'a is groter dan b';
} elseif ($a < $b) {
    echo 'a is kleiner dan b';
} else {
    echo 'a is gelijk aan b';
}

switch ($a) {
    case 5:
        echo 'a is 5';
        break;
    case 10:
        echo 'a is 10';
        break;
    default:
        echo 'a is geen 5 of 10';
}

Ook de meeste loops zijn opnieuw beschikbaar:

  • for: een loop die een bepaald aantal keer wordt uitgevoerd.
  • foreach: een loop die over alle elementen van een array of object loopt.
  • while: een loop die wordt uitgevoerd zolang een bepaalde voorwaarde waar is.
  • do...while: een loop die minstens één keer wordt uitgevoerd en daarna zolang een bepaalde voorwaarde waar is.

Enkele voorbeelden:

$array = [1, 2, 3, 4, 5];

for ($i = 0; $i < count($array); $i++) {
    echo $array[$i];
}

foreach ($array as $value) {
    echo $value;
}

$i = 0;
while ($i < count($array)) {
    echo $array[$i];
    $i++;
}

$i = 0;
do {
    echo $array[$i];
    $i++;
} while ($i < count($array));

De foreach-loop is een speciale loop die enkel gebruikt kan worden om over een array of object te loopen. Deze loop is heel handig omdat je niet moet nadenken over de lengte van de array of de index van het element dat je wil selecteren. Je kan gewoon over alle elementen van de array loopen en de waarde van het element gebruiken.

De foreach-loop heeft twee vormen:

$array = [1, 2, 3, 4, 5];

foreach ($array as $value) {
    echo $value;
}


$assocArray = ['a' => 1, 'b' => 2, 'c' => 3];

foreach($assocArray as $key => $value){
    echo $key . ' => ' . $value;
}

1.3 Functies Terug naar boven

Net zoals in andere talen kunnen we in PHP gebruik maken van functies. Een functie is een stukje code dat we kunnen hergebruiken in onze applicatie. Dit is handig omdat we zo niet telkens dezelfjsonde code moeten schrijven. We kunnen een functie declareren met de function-keyword:

function sayHello($name) {
    echo 'Hello ' . $name;
}

sayHello('Kevin');

We kunnen zoals hierboven ook parameters meegeven aan een functie. Deze parameters kunnen we dan gebruiken in de functie. We kunnen ook een return-waarde meegeven aan een functie:

function add($a, $b) {
    return $a + $b;
}

$sum = add(5, 10);

echo $sum; // 15

Ook optionele parameters zijn weer aanwezig. Dit zijn parameters die een standaardwaarde hebben en dus niet verplicht zijn om mee te geven:

function sayHello($name = 'World') {
    echo 'Hello ' . $name;
}

sayHello(); // Hello World
sayHello('Kevin'); // Hello Kevin

1.4 Arrays & Objecten Terug naar boven

Net zoals vorig jaar in Programming Essentials 1 en 2 kunnen we in PHP gebruik maken van arrays en objecten. Een array is een lijst van waarden die we kunnen gebruiken om gegevens te groeperen. Een object is een complexere structuur die bestaat uit verschillende eigenschappen.

Om een array te declareren kunnen we onze waarden tussen square brackets [ ] plaatsen en onze verschillende elementen scheiden met een komma:

$array = [1, 2, 3, 4, 5];

Om een object te declareren moeten we gebruik maken van de new-keyword en de stdClass-class:

$object = new stdClass();

$object->name = 'Kevin';
$object->role = 'Teacher';

Later gaan we zelf classes maken en objecten instantiëren, maar voorlopig is dit voldoende om te weten.

Ook zijn associatieve arrays weer van de partij. Dit zijn arrays waarbij we zelf de index van de waarden kunnen bepalen:

$assocArray = ['a' => 1, 'b' => 2, 'c' => 3];

Associatieve arrays zijn heel handig wanneer we een lijst van waarden willen groeperen en we deze waarden willen kunnen selecteren aan de hand van een bepaalde index.

We kunnen deze arrays en objecten gebruiken in combinatie met de foreach-loop om over alle elementen te loopen zoals hierboven beschreven.

Multidimensionale arrays zijn ook weer aanwezig. Dit zijn arrays die arrays bevatten:

$multiArray = [
    [1, 2, 3],
    [4, 5, 6],
    [7, 8, 9]
];

1.5 Files Terug naar boven

Aangezien we vanaf nu gaan werken met een backend, is het belangrijk dat we kunnen werken met bestanden. In PHP kunnen we bestanden openen, lezen, schrijven en sluiten. Hieronder een overzicht van de meest gebruikte functies:

  • fopen: opent een bestand.
  • fclose: sluit een bestand.
  • fread: leest een bestand.
  • fwrite: schrijft naar een bestand.
  • file_get_contents: leest de inhoud van een bestand.

Enkele voorbeelden:

$file = fopen('file.txt', 'r');

while (!feof($file)) {
    echo fgets($file) . '
';
}

fclose($file);

$file = fopen('file.txt', 'w');

fwrite($file, 'Hello World');

fclose($file);

Met deze functies kunnen we bestanden openen, lezen, schrijven en sluiten. Dit is handig wanneer we bijvoorbeeld gegevens willen opslaan in een bestand of wanneer we gegevens willen inlezen uit een bestand.

We zien bij de fopen-functie dat we een tweede parameter kunnen meegeven. Dit is een string die aangeeft hoe we het bestand willen openen:

  • r: lezen.
  • w: schrijven.
  • a: schrijven aan het einde van het bestand.
  • r+: lezen en schrijven.
  • w+: lezen en schrijven, bestaande inhoud wordt overschreven.
  • a+: lezen en schrijven, schrijven aan het einde van het bestand.

Indien we een reeds bestaand bestand willen openen en we willen de inhoud behouden, dan moeten we de a-modus gebruiken. Als we de w-modus gebruiken gaan we het huidige bestand overschrijven.

Let op met het gebruik van deze functies. Het is belangrijk dat je de juiste permissies hebt om bestanden te openen, lezen en schrijven. Denk hiervoor terug aan de file permissions die jullie hebben gezien in Desktop OS.

Indien je enkel de inhoud van een bestand wilt inlezen zonder dat je deze wilt aanpassen, dan kan je gebruik maken van de file_get_contents-functie:

$content = file_get_contents('file.txt');

echo $content;

1.6 Ingebouwde Functies Terug naar boven

Er zijn zeer veel ingebouwde functies beschikbaar in PHP. Deze functies kunnen we gebruiken om bepaalde taken uit te voeren zonder dat we zelf de code moeten schrijven. Indien je ooit een bepaalde functionaliteit nodig hebt, is het altijd een goed idee om eerst te kijken of er geen ingebouwde functie bestaat die deze taak kan uitvoeren.

De officiële PHP-documentatie is een goede plaats om te beginnen. Hier kan je alle ingebouwde functies van PHP terugvinden en de bijhorende documentatie lezen. Dit is een goede gewoonte om aan te leren, aangezien je later in je carrière vaak zal moeten werken met verschillende programmeertalen en frameworks.

Je kan de officiële PHP-documentatie terugvinden op php.net.

Enkele voorbeelden van ingebouwde functies:

$string = 'Hello World';
echo strlen($string); // 11
echo strtoupper($string); // HELLO WORLD
echo strtolower($string); // hello world


$array = [1, 2, 3, 4, 5];
echo count($array); // 5
echo array_sum($array); // 15


$number = 5.5;
echo round($number); // 6
echo floor($number); // 5


$timestamp = time();
echo date('Y-m-d H:i:s', $timestamp); // 2024-09-24 14:00:00

Dit zijn maar enkele voorbeelden van de vele ingebouwde functies die beschikbaar zijn. Op termijn zal je deze functies leren kennen en kan je ze gebruiken in je eigen code. Indien je moet gebruik maken van deze functies in de oefeningen zal ik een link voorzien naar de documentatie zodat je deze kan raadplegen.
